Lyo Benchmark Dashboards

Single-instance performance snapshots for the query API (k6), encryption library, and compression library. Data loads automatically from generated scripts — no manual table updates.

Refresh data

After running benchmarks, regenerate manifests:

python3 scripts/benchmarks/build-manifests.py

k6 runs also refresh automatically via k6/framework-person/run_all.sh.

Then reload the HTML page in your browser.

Generated data lives in docs/benchmarks/data/.
