Lyo Benchmark Dashboards

Single-instance performance snapshots across the Lyo framework: the query API (k6) plus BenchmarkDotNet suites for encryption, compression, hashing, caching, query/CRUD, CSV, XLSX, and locking. Data loads automatically from generated scripts — no manual table updates.

Refresh data

Run the BenchmarkDotNet suites and regenerate every report:

scripts/benchmarks/run-dotnet-benchmarks.sh

Or just rebuild the dashboard data from existing artifacts / k6 results:

python3 scripts/benchmarks/build_manifests.py

Each report follows the unified lyo.bench/v1 schema (type: "micro" or "load") and opens in report.html. Then reload this page.

Generated data lives in docs/benchmarks/data/ (<name>.json + <name>.js + registry.js).
