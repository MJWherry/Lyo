# Lyo.Cli pack/install

Pack and install the global `lyo` dotnet tool from Lyo.Cli.

Thin wrapper around `dotnet pack` / `dotnet tool install|update|uninstall` for the PackAsTool project under Lyo.Net/Tools/Lyo.Cli. Library NuGet packs still skip Tools/; use this script for the CLI tool package.

## Commands

- `python3 scripts/cli/pack_install.py pack`. Pack Lyo.Cli to artifacts/cli
- `python3 scripts/cli/pack_install.py install`. dotnet tool install -g Lyo.Cli from artifacts/cli
- `python3 scripts/cli/pack_install.py update`. Force-reinstall global Lyo.Cli from artifacts/cli (same version OK)
- `python3 scripts/cli/pack_install.py pack-install`. Pack then force-reinstall the global tool (needed when version stays 1.0.0)
- `python3 scripts/cli/pack_install.py uninstall`. Remove the global Lyo.Cli tool

## Notes

- Default version is 1.0.0 (`-v`); nupkg dir defaults to artifacts/cli or LYO_CLI_NUPKG_DIR
- pack-install / update uninstall then install so rebuilding 1.0.0 still refreshes the tool (`dotnet tool update` no-ops on same version)
- After install, invoke as `lyo` (ToolCommandName)
- crypt = encryption; enc = Lyo.TextEncoding (base64/hex/charset)
