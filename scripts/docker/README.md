# Docker benchmark runner

Resolve BDN targets and run suites inside the Lyo benchmarks container.

Compose-backed runner. Default starts the container detached and returns immediately. Mid-run mounts update docs/benchmarks/data and portfolio history as each suite finishes.

## Commands

- `python3 scripts/docker/run.py Lyo.Encryption.Benchmarks` — Build/start one suite in the background (returns immediately)
- `python3 scripts/docker/run.py --fg '*.Benchmarks'` — Foreground logs; quote globs so the shell does not expand them
- `python3 scripts/docker/run.py --wait Lyo.Encryption.Benchmarks` — Detached run that blocks until the container exits (then host portfolio sync)
- `python3 scripts/docker/run.py --build-only` — Rebuild the image without starting a suite
- `python3 scripts/docker/resolve_targets.py '*.Benchmarks'` — List resolved project names for a filter

## Notes

- entrypoint.py runs run_dotnet.py inside the container with portfolio sync enabled
- Compose mounts docs/benchmarks/{data,history} and apps/portfolio/public/benchmarks/history
- Default is background; use --wait or --fg if you want the CLI to block
- With --wait/--fg on success, run.py also calls build_manifests.py --sync-portfolio-only as a host safety net
