# k6 framework-person matrix

Load / stress / spike / soak / ceiling matrix for person Query APIs.

Python matrix runner builds shared TypeScript clients, runs selected k6 scenarios, then refreshes the load-test dashboard via build_manifests.py --k6-only. Scenario details and env vars live in the hand-maintained k6/framework-person/README.md.

## Commands

- `python3 k6/framework-person/run_all.py` — Run the full matrix
- `python3 k6/framework-person/run_all.py spike` — Spike profile across query endpoints
- `python3 k6/framework-person/run_all.py query spike` — Combine group aliases / keywords
- `MODE=smoke python3 k6/framework-person/run_all.py` — One VU / one iteration per selected test
- `CACHE_HIT_MODE=true RUN_LABEL=ceiling-cached python3 k6/framework-person/run_all.py ceiling` — Saturation runs with cache-hit request shapes

## Notes

- TEST_FILTER accepts comma-separated keywords (same as CLI args)
- Results land under k6/framework-person/results/<optional-label-><timestamp>/
- CONTINUE_ON_FAILURE=true keeps going after a failed scenario
