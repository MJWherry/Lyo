# Lyo.Leaderboard.Api.Client

Calls board, property, invite, entry, adjustment, and standing routes. `RedeemInviteAsync` and `CreateEntryAsync` can send the guest actor header. Bind section `LeaderboardApi`.

## Features

- `AddLeaderboardApiClientFromConfiguration` registers `ILeaderboardApiClient`.
- 204 responses use `PostExpectingNoContentAsync`.

## Examples

### Register the client

```csharp
services.AddLeaderboardApiClientFromConfiguration(configuration);
```
