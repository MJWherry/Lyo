# Lyo.Comic.Api

Maps CRUD on `ComicDbContext` entities (series, alternate titles, volumes, chapters, pages, characters) via `Lyo.Api` `CreateBuilder` with entity-as-both DTOs. Register the store with `AddComicApiFromConfiguration` (or `AddPostgresComicStore` plus `AddLyoCrudServices<ComicDbContext>`), then call `BuildComicGroup`. Standalone host: `Lyo.Comic.Api.Host`.

## Features

- `BuildComicGroup` maps Comic CRUD for series, alternate titles, volumes, chapters, pages, and characters.
- `AddComicApiFromConfiguration` registers the Postgres store, CRUD services, and an identity `ILyoMapper` for entity-as-both mapping.

## Examples

### Map the Comic API

```csharp
services.AddLocalCache();
services.AddLyoQueryServices();
services.AddComicApiFromConfiguration(configuration);
var app = builder.Build();
app.BuildComicGroup();
```
