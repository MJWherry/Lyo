# Lyo.Comic.Api.Host

Thin host: `AddComicApiFromConfiguration` and `BuildComicGroup`. Prefer embedding those calls in another host when composing APIs. Binds http://localhost:5101 (see Properties/launchSettings.json).

## Features

- OpenAPI and Scalar in Development only.
- Local cache + query services as required by Comic CRUD.

## Examples

### Start the standalone host

```bash
dotnet run --project Lyo.Net/Apps/Comic/Lyo.Comic.Api.Host
```
