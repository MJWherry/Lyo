# Lyo.Billing.Client

Typed HTTP client targeting the Lyo Billing API (`netstandard2.0;net10.0`).

Blazor hosts and workers should call draft/issue/void/pay through this client against an API host that runs [`Lyo.Billing.Api`](../Lyo.Billing.Api/README.md). Do **not** inject `IConfiguration` to build invoice PDF hrefs — use `IBillingClient.InvoicePdfHref`.

```csharp services.AddBillingClient<ApiClient>(); services.AddBillingClient<ApiClient>(o => o.RoutePrefix = "api"); services.AddBillingClientFromConfiguration<ApiClient>(configuration); // section BillingClientOptions // or resolve the API client through a factory: services.AddBillingClient(sp => sp.GetRequiredService<IApiClient>()); ```

```csharp var draft = await billing.CreateDraftAsync(new CreateDraftInvoiceRequest { ClientId = clientId }); await billing.AddLineAsync(draft.Id, new InvoiceLineRecord { Description = "Design", Quantity = 2m, UnitAmount = 100m }); var issued = await billing.IssueAsync(draft.Id); await billing.PayAsync(issued.Id, new RecordInvoicePaymentRequest { Amount = issued.Total, Method = PaymentMethod.Wire }); var pdfHref = billing.InvoicePdfHref(issued.Id); ```

Auth rides on the underlying `IApiClient` / `HttpClient` (the same bearer as other API calls). Invoice PDFs are generated by the Reporting host at `GET /Reporting/Invoices/{id}/pdf`.

## Features

- Typed methods for from-charges, draft, lines, issue, void, pay, summary, and unbilled charges.
- `InvoicePdfHref` builds `{BaseAddress}/Reporting/Invoices/{id}/pdf` so UI does not read `ApiClient:BaseUrl` from configuration.

## Examples

### Register the client

```csharp
services.AddLyoApiClient();
services.AddBillingClient<ApiClient>();
```
