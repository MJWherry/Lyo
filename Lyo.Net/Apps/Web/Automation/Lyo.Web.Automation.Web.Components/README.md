# Lyo.Web.Automation.Web.Components

AutomationPlanHost is a selection bar plus Manage, Editor, and Runner. Manage is a query grid on Automation/Plans. Editor is AutomationPlanWorkbench. Runner is
AutomationPlanRunnerView, a two-pane view of each step screenshot and context. Pass IAutomationPlanClient and IApiClient in. The components do not inject them and do not launch a
browser. Recording stays on the TypeScript studio.

## Features

- Forms cover navigate, reload, delay, find, act, extract, store, capture network, download URLs, store string list, and extract sources. Each form shows a readable label.
- A step the catalog does not own stays in the document. The JSON pane is JsonEditor, tree and raw. Apply replaces the steps. Invalid JSON leaves the plan alone.
- Run posts the plan, polls until the run settles, then shows the transcript and viewport snapshots. The browser stays on the API host.

## Examples

### Host page

```razor
<AutomationPlanHost Client="Client" />

@code {
    [Inject]
    private IAutomationPlanClient Client { get; set; } = null!;
}
```
