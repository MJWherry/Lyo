# Lyo.IO.FileSystem.Web.Components

MudBlazor tree that lazy-lists folders through `IFileTreeSource`. It does not know FileStorage. Wrap `IFileSystem` with `FileSystemTreeSource`, or supply an HTTP source.

## Features

- **Lazy expand.** Children load from `IFileTreeSource.ListChildrenAsync` when a directory is opened.
- **Optional properties.** Extra `FileSystemEntry.Properties` (for example FileId or presence) show as chips.

## Examples

### Memory file system

```csharp
<LyoFileTree Source="_source" RootPath="@_fs.RootPath" />

@code {
    private readonly MemoryFileSystem _fs = new();
    private IFileTreeSource _source = default!;
    protected override void OnInitialized() => _source = new FileSystemTreeSource(_fs);
}
```
