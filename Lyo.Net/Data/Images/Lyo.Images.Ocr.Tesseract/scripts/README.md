# Tesseract Linux native libs

Symlink distro Leptonica/Tesseract/libdl names for charlesw/Tesseract NuGet.

InteropDotNet looks under $(OutputPath)x64/ for versioned .so names. This script creates those symlinks (and libdl.so beside the TFM output) from system libraries.

## Commands

- `python3 Lyo.Net/Data/Images/Lyo.Images.Ocr.Tesseract/scripts/setup_linux_tesseract_nuget_libs.py "$PWD/Lyo.Net/Data/Images/Lyo.Images.Ocr.Tesseract.Tests/bin/Debug/net10.0"`. Link libs into a TFM output folder after dotnet build
- `python3 .../setup_linux_tesseract_nuget_libs.py .../net10.0 --also-system`. Also install symlinks under /usr/local/lib (sudo)

## Notes

- Apt: libtesseract5 + libleptonica-dev (or libleptonica6) + tesseract-ocr-eng for eng.traineddata
- MSBuild opt-in: PrepareTesseractLinuxNativeLibs=true on test/host projects (not packable libraries) runs this script after Build on Linux with --allow-missing so compile does not require distro Tesseract
- Pass the TFM folder (.../net10.0), not .../x64
