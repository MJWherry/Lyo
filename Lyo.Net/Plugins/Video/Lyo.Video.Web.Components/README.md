# Lyo.Video.Web.Components

Blazor components for browsing a video catalog. `VideoTitleSearch` asks the host to search. `VideoTitleDetail` shows a movie (runtime, overview, credits, YouTube id) or a series season and episode list. Cover URLs and tag lists come from the host. YouTube types arrive through `Lyo.Google.Youtube.Models`. Components do not take a database context.

## Features

- **Search.** Title, kind, year, and an optional tag list. The catalog store does not apply tags; the host does.
- **Series.** Seasons and episodes in the order the host loaded them.
- **Movie.** Runtime, overview, credits, and the stored YouTube video id when present.

## Examples

### Host wiring

```razor
<VideoTitleSearch SearchFunc="SearchAsync" AvailableTags="@_tags" ResolveCoverUrlFunc="CoverUrl" OnTitleOpen="OpenAsync" />
<VideoTitleDetail Title="@_title" CoverImageUrl="@CoverUrl(_title)" />
```
