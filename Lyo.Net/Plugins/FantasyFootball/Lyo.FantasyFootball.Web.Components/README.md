# Lyo.FantasyFootball.Web.Components

`FantasyFootballWorkbench` injects `IApiClient` and talks to the FantasyFootball HTTP API. Pass `LeagueId`, `SeasonId`, and an optional `RoutePrefix` (default `FantasyFootball`).

## Features

- Refresh pulls ESPN through the API, then reloads chats and trades from the store.
- Chats lists league chat and direct messages, then posts to the open topic.
- Trades lists recent and pending proposals and proposes from the stored roster.

## Examples

### Host the workbench

```razor
<FantasyFootballWorkbench LeagueId="leagueId" SeasonId="seasonId" />
```
