# Lyo.Recipe.Web.Components

Drop `RecipeManagement` on a host page for Recipes, Ingredients, Categories, and Units. The recipe editor is a large dialog: reorderable ingredient lines and steps, unit
autocomplete, step photos, and a separate cook stepper. Uses `IApiClient` for QueryProject/CRUD and `IRecipeClient` for extra routes. This package has no `AddXxx` DI registration.

## Features

- `RecipeManagement` tab shell for recipes, ingredients, categories, and units.
- `RecipeView` edits lines and steps before the first save. `RecipeCookView` walks ingredients, then one step at a time, and can scale servings.
- `RecipeColorHelper` maps status, difficulty, and attachment role to MudBlazor / `LyoChipHue`.

## Examples

### Host page

```razor
<RecipeManagement ApiClient="ApiClient" RecipeClient="RecipeClient" BaseRoute="Recipe" FileStorageApiRoutePrefix="Workbench/FileStorage" />
```
