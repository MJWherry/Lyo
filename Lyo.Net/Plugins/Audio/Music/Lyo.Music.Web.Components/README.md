# Lyo.Music.Web.Components

Blazor components for browsing a music catalog. `MusicReleaseSearch` asks the host to search. `MusicReleaseDetail` shows credits and tracks for a release the host already loaded.
Cover URLs and tag lists come from the host. Components do not take a database context.

## Features

- **Search.** Title, kind, year, and an optional tag list. The catalog store does not apply tags; the host does.
- **Detail.** Track list ordered as the host loaded it, plus credits. Lyrics are not shown.

## Examples

### Host wiring

```razor
<MusicReleaseSearch SearchFunc="SearchAsync" AvailableTags="@_tags" ResolveCoverUrlFunc="CoverUrl" OnReleaseOpen="OpenAsync" />
<MusicReleaseDetail Release="@_release" CoverImageUrl="@CoverUrl(_release)" />
```
