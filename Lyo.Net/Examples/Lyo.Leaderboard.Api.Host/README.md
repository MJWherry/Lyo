# Lyo.Leaderboard.Api.Host

Thin net10 host. Prefer embedding `AddLeaderboardApi` in another process. This host also maps JWKS, auth, and token endpoints.

## Features

- Not packable.
- Reads `PostgresLeaderboard` and registers the algorithm catalog on that same connection string.
