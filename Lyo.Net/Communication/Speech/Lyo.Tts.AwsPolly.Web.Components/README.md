# Lyo.Tts.AwsPolly.Web.Components

MudBlazor workbench for trying [`Lyo.Tts.AwsPolly`](../Lyo.Tts.AwsPolly/README.md) from a host app.

## Components

- `AwsPollyWorkbench` includes voice, audio format, and language selectors backed by `AwsPollyVoiceId`, a multi-line text field, and **Synthesize** / **Test Connection** actions.
- Resolves `AwsPollyTtsService` and `AwsPollyOptions` from DI. The host must register those via [`Lyo.Tts.AwsPolly`](../Lyo.Tts.AwsPolly/README.md) first.
- Calls `AwsPollyTtsService.SynthesizeAsync(...)` with a populated `AwsPollyTtsRequest`. Status text goes to `MudAlert`; feedback goes through `ISnackbar`.
- Plays the returned audio bytes inline through `IJsInterop`.

## Supported framework

`net10.0`
