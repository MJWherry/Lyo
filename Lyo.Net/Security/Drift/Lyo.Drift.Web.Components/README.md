# Lyo.Drift.Web.Components

Drop DriftManagement on a host page for instance registry (stop/delete), structure snapshots (payload viewer + DiffAgainst), stored diffs, and live change events. Uses injected IApiClient and a configurable BaseRoute. Grids do not Select jsonb payload columns.

## Features

- **Off-grid payloads.** Snapshot JSON is loaded on demand into JsonViewDialog.
- **Named hash.** Snapshot grid shows content_hash_algorithm (sha256) plus a truncated hex digest.
- **Actions.** Stop and delete instances; DiffAgainst two snapshots of the same kind.

## Examples

### Host

```razor
@using Lyo.Drift.Web.Components

<DriftManagement BaseRoute="http://localhost:5251/Drift" />
```
